# Bewegungsbilder Zuhause: Prompt für ChatGPT

Stand 11.11.2026: Studio (22 Übungen) und Aufwärmen (24) haben alle ein
Bewegungsbild, im freien Bereich (Kurzhantel, Langhantel, Kettlebell, Band,
Ringe, Box, Bank, Körpergewicht) 88 von 93. Die Teile 1 bis 4 und die erste
Nachlieferung sind eingebaut; offen sind die fünf Motive unter
„Nachlieferung 2“ am Ende.

So gehst du vor:

- **Je Teil ein eigener Chat.** Prompt einfügen, die genannten Bilder aus den
  bisherigen ZIP-Paketen anhängen.
- **Bricht ChatGPT ab:** „weiter“ schreiben, oder einen neuen Chat mit
  demselben Prompt und „Beginne mit Z…“ (die nächste offene Nummer).
- **Die ZIP-Pakete an Claude schicken.** Jedes Bild wird geprüft
  (Ausrichtung, Phasen, Zeichenfehler), eingebaut und die Nummern genannt,
  die neu gemacht werden müssen.
